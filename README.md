# SolarPark
SolarPark – Parcarea viitorului, alimentată de soare
SolarPark este un website de prezentare pentru o afacere fictivă care propune parcări auto acoperite cu panouri fotovoltaice (carporturi solare). Proiectul ilustrează modul în care un spațiu de parcare poate oferi protecție automobilelor și poate produce energie electrică din surse regenerabile.
Slogan: „Parchezi inteligent. Produci energie verde.”

Despre proiect
Scopul website-ului este de a prezenta conceptul SolarPark, serviciile oferite și avantajele parcărilor fotovoltaice, precum și de a facilita contactul dintre companie și potențialii clienți.

SolarPark este un proiect demonstrativ realizat în cadrul disciplinei Bazele antreprenoriatului.
Obiective
- Promovarea utilizării energiei regenerabile.
- Prezentarea conceptului de carport fotovoltaic.
- Informarea vizitatorilor despre serviciile și avantajele SolarPark.
- Crearea unei prezențe online pentru afacere.
- Încurajarea mobilității electrice și a utilizării eficiente a spațiului.
Funcționalități
- Pagină principală cu prezentarea SolarPark și mesaj publicitar.
- Secțiune „Despre noi”.
- Prezentarea serviciilor companiei.
- Secțiune cu avantajele parcării fotovoltaice.
- Explicarea vizuală a modului de funcționare.
- Galerie foto.
- Formular de contact cu validarea câmpurilor obligatorii, dacă funcționalitatea este implementată.
- Navigare între secțiuni.
- Interfață adaptată pentru desktop, tabletă și telefon.
Tehnologii utilizate
Completează această listă în funcție de tehnologiile folosite efectiv în proiect:
- HTML5 – structura paginilor.
- CSS3 – stilizarea și adaptarea interfeței.
